# Eden cheat backup

Backup of the cheat files from Eden (Android) `files/load/`.

Layout: `<TitleID>/<mod name>/<BuildID>.txt`

To restore, copy each file back to
`/sdcard/Android/data/dev.eden.eden_emulator/files/load/<TitleID>/<mod name>/cheats/<BuildID>.txt`
(note the extra `cheats/` folder on the device).

The file name is the game's Build ID, so a cheat only loads on the exact game version it was made for.

| Title ID | Game | Notes |
|---|---|---|
| 01003E601E324000 | DRAGON QUEST III HD-2D Remake | BID 6F49452BD0B343B1 (base v1.0.0). No-encounter toggle and speed x2 were ported by pattern matching from DQ1+2 |
| 0100D7C01F254000 | DRAGON QUEST I & II HD-2D Remake | BID DDB633241838C090 (v1.0.2). Ported from the v1.0.1 set; No Encounter is a ZL + D-Pad toggle |

Other folders are cheats collected earlier for other games.
